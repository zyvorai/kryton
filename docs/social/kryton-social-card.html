One API. Real Windows behind it.

Portals, CI, and automation call one contract. Kubernetes, KubeVirt, and dockur stay behind the provider boundary — stable machine UUIDs end to end.

CALL1

REST + events

`krytonctl` or HTTP against `/api/v1/machines` — OpenAPI served from the daemon.

ROUTE2

Provider pick

`demo` for eval, `dockur` for lab KVM hosts, `kubevirt` for production clusters.

CREATE3

Machine lifecycle

Start, stop, TTL expiry, snapshots — console URLs when the backend supports install progress.

SECURE4

API keys / proxy

Secure-by-default auth; lab auto-auth only when explicitly enabled for shared labs.

OBSERVE5

SSE + webhooks

CloudEvents history, operator dashboard, `krytonctl doctor` against live backends.
